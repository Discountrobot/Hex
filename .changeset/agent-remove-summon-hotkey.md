Removed the "Summon Agent Window" hotkey and its setting. With the proactive trigger path gone, the voice window only ever appears in response to a Claude hook (which already brings the card up on its own), so a dedicated summon shortcut had nothing left to do. The now-unreachable "No Claude sessions" empty state was removed too. A passively-appeared card is engaged by tapping the agent selector or clicking the reply field.
